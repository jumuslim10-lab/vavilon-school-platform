## VAVILON - Платформа управления школами

Полнофункциональная система управления образовательными учреждениями.

### Реализованные модули (8 модулей)

- **Электронный дневник** - оценки учеников по предметам
- **Электронный журнал** - таблица оценок для учителей
- **Расписание уроков** - недельная сетка занятий
- **Домашние задания** - создание и сдача с файлами
- **Посещаемость** - отметка присутствия
- **Учебные материалы** - библиотека документов
- **Сообщения** - внутренняя переписка
- **Уведомления** - центр оповещений

### Технологии

- Next.js 16 + React 19 + TypeScript
- Supabase (PostgreSQL + Auth + Storage)
- Tailwind CSS 4.0 + Turbopack
- 35+ таблиц с Row Level Security

### Запуск

```bash
npm install --legacy-peer-deps
npm run dev
npm run build
```

### Структура

```
app/          - страницы (login, dashboard, diary, journal, etc)
components/   - React компоненты
lib/          - утилиты и Supabase клиенты
supabase/     - SQL миграции
```

### Роли

- student: дневник, расписание, задания
- teacher: журнал, посещаемость, материалы
- school_admin: все модули
- parent: дневник детей

Создано для школ Кыргызстана.
